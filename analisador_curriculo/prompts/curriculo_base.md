# Projetos & Experiência Prática

## Job Web Scraper | Automação, API & Bot Telegram (Projeto Pessoal)

### Tecnologias

Python, FastAPI, Playwright, PostgreSQL, SQLAlchemy, Supabase, Docker, Linux, Git/GitHub, GitHub Actions, Render e Telegram API.

### Descrição

Desenvolvi uma solução end-to-end para otimizar a busca por empregos, substituindo pesquisas manuais por uma pipeline automatizada de coleta, filtragem e notificação.

### Destaques Técnicos e Impacto

- **Automação & Web Scraping:** Desenvolvimento de scrapers resilientes utilizando Playwright para navegação e autenticação via persistência de cookies de sessão (LinkedIn e InfoJobs).

- **API REST & Persistência:** Criação de API com FastAPI e SQLAlchemy para gestão das vagas, persistidas em banco de dados PostgreSQL (Supabase).

- **Integração & Mensageria:** Integração com Telegram Bot API, enviando alertas instantâneos com botões interativos para gestão de status das vagas (Rejeitada, Aplicada e Salva).

- **DevOps & Agendamento:** Automação de execução com GitHub Actions (Cron jobs), rodando scrapers periodicamente de forma 100% autônoma e realizando o deploy da API no Render.
